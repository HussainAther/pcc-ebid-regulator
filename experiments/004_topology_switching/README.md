# Experiment 004 — Topology-switching regulation

This experiment asks whether **structural environmental variety** is more
informative than scalar coupling drift for connecting PCC/EBID to classical
regulator theorems.

## 004A — Structural requisite variety

The active PCC interaction topology switches among up to four toy regimes.
The regulator is told the active topology exactly, so model uncertainty is
held at an optimistic minimum. Only action repertoire size is varied.

Primary question: does increasing the number of dynamically accessible
interaction structures increase the minimum repertoire needed to meet a fixed
regulation-error criterion?

## 004B — Structural model adequacy

Action repertoire is fixed at nine actions. Controllers differ only in what
structural information they use: active-topology oracle, fixed canonical
model, fixed reverse model, state-only reactive control, and short-history
control.

Primary question: when topology changes, does a controller with the correct
structural model achieve lower error than controllers with structurally wrong
or model-free representations?

## Claim boundary

These topologies are deliberately minimal computational probes. They are not
claimed to be canonical PCC equations, nor does success/failure constitute a
proof or refutation of Ashby's Law or the Good Regulator Theorem.
